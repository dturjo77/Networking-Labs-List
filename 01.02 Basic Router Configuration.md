
# **Router Basic Configuration**

### **1. Enter Privileged Mode from User Mode**

```
Router> enable
Router#
```

---

### **2. Enter Global Configuration Mode**

```
Router# configure terminal
Router(config)#
```

---

### **3. Set Hostname**

```
Router(config)# hostname R1
R1(config)#
```

---

### **4. Set Banner MOTD**

```
R1(config)# banner motd #
**************************************************
*     WARNING: Authorized Access Only!           *
*     Unauthorized access is strictly prohibited.*
**************************************************
#
R1(config)#
```

---

### **5. Password Security**

```
R1(config)# enable secret cisco123
R1(config)# service password-encryption
R1(config)#
```

---

### **6. Console Line Configuration**

```
R1(config)# line console 0
R1(config-line)# password console123
R1(config-line)# login
R1(config-line)# exec-timeout 5 0
R1(config-line)# logging synchronous
R1(config-line)# exit
R1(config)#
```

---

### **7. VTY Line Configuration (Remote Access)**

```
R1(config)# line vty 0 15
R1(config-line)# password vty123
R1(config-line)# login
R1(config-line)# exec-timeout 5 0
R1(config-line)# logging synchronous
R1(config-line)# transport input telnet
R1(config-line)# exit
R1(config)#
```

---

### **8. Configure Domain & Create Local User**

```
R1(config)# no ip domain-lookup
R1(config)# ip domain-name cisco.lab
R1(config)# username admin privilege 15 secret StrongPass123
R1(config)#
```

---

### **9. Configure Interface IP Address**

```
R1(config)# interface gigabitEthernet 0/0
R1(config-if)# ip address 192.168.1.1 255.255.255.0
R1(config-if)# no shutdown
R1(config-if)# exit
R1(config)#
```

---

### **10. Configure Additional Interface (Optional)**

```
R1(config)# interface gigabitEthernet 0/1
R1(config-if)# ip address 192.168.2.1 255.255.255.0
R1(config-if)# no shutdown
R1(config-if)# exit
R1(config)#
```

---

### **11. Set Clock (from Privileged Mode)**

```
R1(config)# exit
R1# clock set 20:13:00 1 May 2026
R1# clock timezone BD +6
R1#
```

---

### **12. Verify & Save Configuration**

```
R1# show running-config
R1# show startup-config

R1# write memory
or
R1# copy running-config startup-config
```

---

## **Key Difference (Switch vs Router)**

* Switch → Management IP via **VLAN interface**
* Router → IP assigned directly to **physical interfaces (G0/0, G0/1)**
