Switch Basic Configuration 

#### ১. User Mode থেকে Privilege Mode এ যাওয়া
```
Switch> enable
Switch#
```

#### ২. Global Configuration Mode এ যাওয়া
```
Switch# configure terminal
Switch(config)#
```

#### ৩. Hostname সেট করা
```
Switch(config)# hostname S1
S1(config)#
```

#### ৪. Banner MOTD সেট করা
```
S1(config)# banner motd #
**************************************************
*     WARNING: Authorized Access Only!           *
*     Unauthorized access is strictly prohibited.*
**************************************************
#
S1(config)#
```

#### ৫. Password Security
```
S1(config)# enable secret cisco123
S1(config)# service password-encryption
S1(config)#
```

#### ৬. Console Line Configuration
```
S1(config)# line console 0
S1(config-line)# password console123
S1(config-line)# login
S1(config-line)# exec-timeout 5 0
S1(config-line)# logging synchronous
S1(config-line)# exit
S1(config)#
```

#### ৭. VTY Line Configuration (Remote Access)
```
S1(config)# line vty 0 15
S1(config-line)# password vty123
S1(config-line)# login
S1(config-line)# exec-timeout 5 0
S1(config-line)# logging synchronous
S1(config-line)# transport input telnet
S1(config-line)# exit
S1(config)#
```

#### ৮. Domain ও Local User তৈরি
```
S1(config)# no ip domain-lookup
S1(config)# ip domain-name cisco.lab
S1(config)# username admin privilege 15 secret StrongPass123
S1(config)#
```

#### ৯. Management IP (VLAN 1) সেট করা
```
S1(config)# interface vlan 1
S1(config-if)# ip address 192.168.1.10 255.255.255.0
S1(config-if)# no shutdown
S1(config-if)# exit
S1(config)#
```

#### ১০. Default Gateway সেট করা
```
S1(config)# ip default-gateway 192.168.1.1
S1(config)#
```

#### ১১. Clock সেট করা (Privilege Mode থেকে)
```
S1(config)# exit
S1# clock set 20:13:00 1 May 2026
S1# clock timezone BD +6
S1#
```

#### ১২. Configuration যাচাই ও সেভ করা
```
S1# show running-config
S1# show startup-config

S1# write memory
বা
S1# copy running-config startup-config
```

## Switch Basic Configuration — বিস্তারিত আলোচনা

### ১. Mode Hierarchy বোঝা

Cisco IOS এ তিনটি প্রধান mode আছে, একটির ওপর আরেকটি নির্ভরশীল:

```
Switch>          ← User EXEC Mode       (enable দিয়ে উঠুন)
Switch#          ← Privileged EXEC Mode  (configure terminal দিয়ে নামুন)
Switch(config)#  ← Global Config Mode   (interface/line দিয়ে ঢুকুন)
Switch(config-if)# ← Interface Config
Switch(config-line)# ← Line Config
```

`exit` দিলে এক ধাপ পেছনে যায়। `end` বা `Ctrl+Z` দিলে সরাসরি `#` mode এ ফিরে আসে।

---

### ২. enable vs enable secret

অনেকে `enable password` আর `enable secret` গুলিয়ে ফেলেন:

| বিষয় | `enable password` | `enable secret` |
|---|---|---|
| Encryption | Type-7 (দুর্বল) | MD5 Hash (শক্তিশালী) |
| Running-config এ | Plaintext দেখায় | Hash দেখায় |
| দুটো থাকলে | উপেক্ষিত হয় | সক্রিয় থাকে |

**সবসময় `enable secret` ব্যবহার করুন।**

---

### ৩. Console vs VTY — পার্থক্য

**Console (line console 0):** Physical cable লাগিয়ে সরাসরি switch এ connect। Network না থাকলেও কাজ করে — তাই troubleshooting এ সবচেয়ে গুরুত্বপূর্ণ।

**VTY (line vty 0 15):** Network এর মাধ্যমে remote access। Switch এর management IP থাকতে হবে। Telnet plaintext পাঠায় — production এ SSH ব্যবহার করুন।

---

### ৪. VLAN 1 SVI এবং Default Gateway

Layer 2 switch কোনো routing করে না — শুধু frame forward করে। কিন্তু switch নিজেকে manage করতে একটি IP দরকার। এই IP দেওয়া হয় **SVI (Switch Virtual Interface)** দিয়ে — এটি কোনো physical port নয়, এটি logical।

`ip default-gateway` দরকার হয় কারণ switch যদি অন্য network এর কোনো device থেকে management packet পায়, সেটা কোথায় পাঠাবে জানে না — তাই router এর IP টা gateway হিসেবে সেট করা হয়।

---

### ৫. RAM vs NVRAM — সবচেয়ে গুরুত্বপূর্ণ যেটা ভুলবেন না

`running-config` আছে **RAM** এ। বিদ্যুৎ গেলে বা reboot করলে সব মুছে যাবে। `write memory` বা `copy running-config startup-config` দিয়ে **NVRAM** এ save করলে reboot এর পরেও config থাকবে।

Lab এ config করার পরে save না করে বের হলে পরের দিন সব গায়েব — এটা খুব সাধারণ ভুল!

### Lab টিপস

**Verification কমান্ড** — কনফিগারেশনের পরে যাচাই করুন:
```
show running-config          ← পুরো config
show interfaces vlan 1       ← Management IP status
show version                 ← IOS version, uptime
show users                   ← কে connected আছে
```

**SSH সক্রিয় করতে** (Telnet এর বদলে) VTY config করার পরে:
```
S1(config)# crypto key generate rsa modulus 2048
S1(config)# ip ssh version 2
S1(config)# line vty 0 15
S1(config-line)# transport input ssh
S1(config-line)# login local
```

Step এ এগোতে উপরের widget এর "পরে →" বাটন চাপুন, বা যেকোনো dot এ click করে সরাসরি যেতে পারবেন।
