Switch Basic Configuration 

#### ১. User Mode থেকে Privilege Mode এ যাওয়া
```
Switch> enable
Switch#
```

#### ২. Global Configuration Mode এ যাওয়া
```
Switch# configure terminal
Switch(config)#
```

#### ৩. Hostname সেট করা
```
Switch(config)# hostname S1
S1(config)#
```

#### ৪. Banner MOTD সেট করা
```
S1(config)# banner motd #
**************************************************
*     WARNING: Authorized Access Only!           *
*     Unauthorized access is strictly prohibited.*
**************************************************
#
S1(config)#
```

#### ৫. Password Security
```
S1(config)# enable secret cisco123
S1(config)# service password-encryption
S1(config)#
```

#### ৬. Console Line Configuration
```
S1(config)# line console 0
S1(config-line)# password console123
S1(config-line)# login
S1(config-line)# exec-timeout 5 0
S1(config-line)# logging synchronous
S1(config-line)# exit
S1(config)#
```

#### ৭. VTY Line Configuration (Remote Access)
```
S1(config)# line vty 0 15
S1(config-line)# password vty123
S1(config-line)# login
S1(config-line)# exec-timeout 5 0
S1(config-line)# logging synchronous
S1(config-line)# transport input telnet
S1(config-line)# exit
S1(config)#
```

#### ৮. Domain ও Local User তৈরি
```
S1(config)# no ip domain-lookup
S1(config)# ip domain-name cisco.lab
S1(config)# username admin privilege 15 secret StrongPass123
S1(config)#
```

#### ৯. Management IP (VLAN 1) সেট করা
```
S1(config)# interface vlan 1
S1(config-if)# ip address 192.168.1.10 255.255.255.0
S1(config-if)# no shutdown
S1(config-if)# exit
S1(config)#
```

#### ১০. Default Gateway সেট করা
```
S1(config)# ip default-gateway 192.168.1.1
S1(config)#
```

#### ১১. Clock সেট করা (Privilege Mode থেকে)
```
S1(config)# exit
S1# clock set 20:13:00 1 May 2026
S1# clock timezone BD +6
S1#
```

#### ১২. Configuration যাচাই ও সেভ করা
```
S1# show running-config
S1# show startup-config

S1# write memory
বা
S1# copy running-config startup-config
```
